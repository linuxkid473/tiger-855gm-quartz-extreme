# Patch reference

Byte-exact tables: [PATCH_TABLES.md](../PATCH_TABLES.md) (generated by `tools/gen_patch_tables.py` from the real files). This page explains what each stage *does*. `file offset = vm + 732` for `__text`.

## The kext chain (`AppleIntel830`)

| Stage | Produced by | What it changes |
|---|---|---|
| p1 | `abiport.py vtables` then `calls` | Rewrites every kext class vtable into the 10.4.8 layout (16 reserved slots removed from each kernel base class) and translates virtual call sites. This is the baseline of the byte tables. |
| p2 | hand patch | Two local fixes: restore a stubbed function body (`31 c0 c3` -> `55 89 e5` at vm 0x10a58) and bypass one call (vm 0x10fcf). |
| p3 | table | 35 one/two-byte slot/relocation corrections (vtable offsets that the automatic pass left at the old values). |
| p4 | hand patch | Restores the call from p2 and changes one compare constant (vm 0x209f, `06` -> `7f`). |
| p5 | hand patch | `IOIntel830Accelerator::start`: NOP two conditional jumps (vm 0x2096 `jnz`, 0x20a0 `jg`) so framebuffers are found on IOKit > 6. |
| p6-p7 | debug | Debug hook on stamp timeouts (cave in dead `dma_test`); repurposed dump labels to display registers. Harmless; kept in the chain. |
| **p8** | one patch | **Always wait on display pipe B** (`83 e0 e2` -> `31 c0 90` at vm 0x18a30). Ring runs, 2D acceleration works. Stable base. |
| **p45b** | `mk_p45.py` | Capture hook at vm 0x12157 (records `this` and the `submit_buffer` address in a slot block at vm 0x13d00) used by the `gpustress` harness. Cave in the dead `Intel830GLContext::dma_test` body. |
| **p48b** | `mk_p48.py` (= p46 + p47 + p48) | p46: **fill the whole GTT with the driver's scratch page** at start-up (cave vm 0x13c80, scratch page at `this+0x5d4`). p47: write Linux's chip registers (`FW_BLC 0x20d8=0x011f0108`, `0x20dc=0x102`, `RENCLK_GATE_D1 0x6204=1`). p48: `MI_ARB_STATE (0x20e4)` is a *masked* register - write `0x00020002`. |
| **p50b** | `mk_p50.py` | `READ_FLUSH` on the post-batch `MI_FLUSH` (`02000000` -> `02000001`, byte at vm 0x1259a) **and** `wbinvd` before every ring-tail write (hook vm 0x12383, cave vm 0x13ce0: `0f 09 \| 89 b0 30 20 00 00 \| jmp back`). `mk_p50.py in out nocache` skips the `wbinvd` hook. |
| **p51** | `mk_p51.py` | **Priming**: the first `BB_START` emission (vm 0x12298, 35 bytes) jumps to a cave that, once (flag byte at vm 0x13d10), pushes a complete self-contained IGT gen2 textured-copy batch (72 dwords) onto the stack, copies it into the ring and continues with the stock `BB_START`. Fixes the cold-boot stall. |
| **p52** | `mk_p50.py p48b p50n nocache` then `mk_p51.py p50n p52` | p51 without the per-submit `wbinvd`. Boots and runs identically; `wbinvd` is defensive only. Current default. |

All caves live in the dead body of `Intel830GLContext::dma_test` (vm 0x13c22-0x140cf). Zero runs in `__cstring` are **not** free space (they hold string slots), and relocation fields must be avoided (`otool -rv`).

## GL side

| File | Tool | Change |
|---|---|---|
| `AppleIntel830GLDriver` | `glfix.py` | Adds `_gldCreateFramebuffer/_gldReclaimFramebuffer/_gldDestroyFramebuffer` stubs (needed by 10.4.8 GLEngine). **Final config uses the pristine driver with the 10.4.1 OpenGL pieces instead**, so `glfix` is only needed for the 10.4.8-GLEngine experiments. |
| `AppleIntel830GLDriver` | `glfix2.py` | Fills the 0x144-byte capability record GLEngine passes to `gldCreateContext`. Same note as above. |
| `AppleIntel830GLDriver` | name patch | `GL_REJECT_HW` -> `HOME` (file offset 0x16840) keeps ordinary apps on the software renderer; see [08](08-video-playback.md). |

## Hardware facts established (Gen2 / 855GM)

* GTT entries are written through MMIO + 0x10000 (write-only); `PGTBL_CTL = 0x4ffe0001`.
* Fence 7 = 64-128 MB, X-tiled, pitch 8192 (tiles are 128 B x 16 rows).
* `MI_FLUSH` bit 0 = `READ_FLUSH`; `MI_ARB_STATE` is a masked register.
* The GPU cannot be reset in software; a wedged engine stays wedged until power-cycle.
* Ring is 4 KB (mask 0xfff). Health check: `lastReadStamp` vs `submitStamp` (healthy gap 2-14; stall = frozen `lastReadStamp`, `HEAD` stuck on the post-batch `MI_FLUSH`, `INSTDONE 0x037b10c1`).
